# MrLogiousBanana's APT Repository

Personal rootless iOS 15 APT repository (Sileo / Zebra) hosted on GitHub Pages.

**Repository URL:** `https://mrlogiousbanana.github.io/repo/`

## Tweaks Available

| Tweak | Version | Description |
|---|---|---|
| **BetterCCXV** | `1.6.0-23` | Full HD album artwork background for the iOS 15 media module with Resolution Gate (no low-res blur). |
| **App Library Control** | `1.2.0` | Custom App Library management (reordering, renaming, hiding) with stable cached identifiers preventing mini-icon disappearance. |
| **QuickSnap CC** | `1.0.1` | Instant silent photo on tap from Control Center, calibrated ISP micro-warmup (0 black frames), zero background camera usage, and 2.5s watchdog. |

## How to Add

- **Sileo:** Tap the link [Add to Sileo](sileo://source/https://mrlogiousbanana.github.io/repo/) or add `https://mrlogiousbanana.github.io/repo/` in Sources.
- **Zebra:** Tap the link [Add to Zebra](zbra://sources/add/https://mrlogiousbanana.github.io/repo/) or add `https://mrlogiousbanana.github.io/repo/` in Sources.
